How learning-to-competency is calculated

One distinct visit with LS counts once for each mentee and topic. Only LS dates before the first dated PC or MC are counted. Full authorized history includes learning before the selected start date; filters select the first competency event, not subsequent assessments.

Stored competency dates are shown for comparison. An earlier stored date, competent status without dated PC/MC, same-day LS/competency, or undated history requires review and is excluded from the statistics. Zero LS means no earlier LS was recorded. Status describes the current staff roster.
