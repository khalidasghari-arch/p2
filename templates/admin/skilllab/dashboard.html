Methodology

Dashboard interpretation: {{ methodology_note }}

Counting approach

  • LS and MC are counted as participant-topic/session instances; one person can contribute multiple records across sessions or topics.
  • Distinct participants count unique mentee records in the filtered dataset.
  • Distinct topics and facilities count unique related records after applying the current filters.
  • MC − LS is a descriptive difference. A negative value means more LS instances than MC instances; a positive value means more MC instances.

Filter behavior

  • Each multi-select filter can include one or more values. Leaving it empty includes all available values.
  • Topic options narrow to the selected thematic areas after applying the filters.
  • Filters apply to the KPI cards, charts, detailed tables, participant summaries, and Excel export.
